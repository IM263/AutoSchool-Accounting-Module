# Модуль учёта в автошколе: группы, занятия, экзамены

Программный модуль для автоматизации административного учёта учебного процесса в автошколе.

## Стек технологий
* **Язык программирования:** C++/CLI (.NET Framework 4.7.2)
* **Доступ к данным:** ADO.NET (`System::Data::SqlClient`)
* **СУБД:** Microsoft SQL Server (SSMS 20)
